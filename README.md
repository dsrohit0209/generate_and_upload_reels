# generate_and_upload_reels
This project intend to build a system that can automate the hectic job of generation and uploading reels one after another. It will allow the content creater to focus on creativity rather than in technicality. 


1. Youtube upload
2. Generate Script
3. Generate voiceover
4. Generate footage
5. Generate/assemble videos
5. Run pipeline

topic -> script -> voiceover + captions -> stock footage -> final video -> upload queue
